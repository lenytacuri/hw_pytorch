# Hello World en PyTorch

Laboratorio introductorio para comprender los fundamentos del aprendizaje supervisado y familiarizarse con PyTorch mediante modelos sencillos de regresión. El propósito es entender cómo un modelo aprende relaciones entre datos al ajustar sus parámetros para reducir el error de sus predicciones.

**Objetivos generales**

- Comprender el papel de los tensores, los pesos y los sesgos en un modelo.
- Entender cómo la función de pérdida, la diferenciación automática y la optimización mediante gradientes permiten el aprendizaje.
- Reconocer cómo las capas y las funciones de activación permiten representar relaciones lineales y no lineales.
- Distinguir el entrenamiento de la inferencia e interpretar los parámetros aprendidos y las predicciones.

Este laboratorio establece una base conceptual y práctica para abordar redes neuronales más complejas con PyTorch.
